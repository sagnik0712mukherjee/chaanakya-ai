# 🧠 The Chaanakya

**The Chaanakya** is an open-source, agentic AI system designed to provide high-quality legal reasoning using large language models, retrieval-augmented generation (RAG), and controlled real-time web search.

The project runs **entirely locally** using **Ollama**, making it private, cost-free, and ideal for experimentation and learning modern LLM system design.

---

## ✨ Key Features

- 🧩 Agentic AI architecture using Agno  
- ⚖️ Legal-domain reasoning with safety-first design  
- 🔍 Hybrid RAG with controlled live web search  
- 💬 Conversational memory with multi-chat support  
- 🖥️ Streamlit UI inspired by ChatGPT  
- 🐳 Fully local, no external LLM APIs  

---

## 🤖 Is This an LLM or an AI Agent?

**Both — by design.**

- The **LLM** is the core reasoning engine.
- The **agent layer** enables planning, tool usage, memory, and verification.
- Together, they form a **legal intelligence system**, not just a chatbot.

This mirrors how real-world AI systems are built in production.

## ⚖️ Legal Safety & Guardrails

Chaanakya is designed with **strong legal safety principles**:

## 🚀 Quick Start

### 1. Install Ollama
```bash
https://ollama.com
```

### 2. Pull the model
```bash
ollama pull llama3.1
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the app
```bash
streamlit run streamlit_app.py
```
